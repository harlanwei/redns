Quick start

Get a ReDNS instance forwarding queries within five minutes.

Build

ReDNS is written in Rust (edition 2024) and builds with a recent stable toolchain: 

$ cargo build --release
# binary: target/release/redns

To enable the optional Linux io_uring UDP backend, build with the io-uring feature. The dashboard frontend is optional too — see Dashboard & API.

Minimal configuration

Create config.yaml in the directory where you will run ReDNS: 

servers:
  - protocol: udp+tcp
    addr: "0.0.0.0:53"
    entry: main

plugins:
  - tag: forward
    type: forward
    args: "1.1.1.1 8.8.8.8"

  - tag: main
    type: sequence
    args:
      - exec: "$forward"

Run and test

$ redns start
# or with an explicit config file:
$ redns start -c /etc/redns/config.yaml
$ dig @127.0.0.1 example.com

;; ANSWER SECTION:
example.com.    21599   IN  A      93.184.215.14

Port 53 is a privileged port. Run ReDNS as root, or grant the capability cap_net_bind_service to the binary (see Operations).

Command line

redns start [-c <config>] [-d <dir>] [--udp-backend <epoll|io-uring>]
redns version
Option Description
start Start the ReDNS server (default subcommand).
-c, --config <file> Path to the YAML config file. When omitted, ReDNS looks for config.yaml then config.yml in the current directory.
-d, --dir <dir> Change the working directory before loading the config. Relative paths in the config (and the default dashboard static_dir) resolve from here.
--udp-backend UDP server backend: epoll (default, works everywhere) or io-uring (Linux only, requires the io-uring build feature). Falls back to epoll automatically when io_uring is unavailable.
version Print the version and git commit, then exit.

Environment variables

  • RUST_LOG — overrides the configured log level (e.g. RUST_LOG=debug redns start).
  • XDG_CACHE_HOME — used to locate the auto-downloaded ASN database ($XDG_CACHE_HOME/redns/, default ~/.cache/redns/).
