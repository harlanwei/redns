has_wanted_ans

Returns true when the current response contains at least one answer record — a stricter variant of has_resp that ignores empty NOERROR or error responses.

matcher used in: matches

Usage

Takes no arguments:

- matches: has_wanted_ans
  exec: accept

Parameters

Parameter Required Type Default Description
— No none n/a This matcher takes no arguments.

Details

  • Only the answer section counts — a response with just authority or additional records does not match.
  • Without a response the matcher returns false.

Examples

# Accept answers with records; forward empty or failed responses elsewhere
- matches: has_wanted_ans
  exec: accept
- exec: "$secondary"

See also

  • has_resp — any response, regardless of contents.
