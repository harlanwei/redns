ReDNS — a fast, scriptable DNS forwarder

ReDNS is a high-performance DNS forwarding server written in Rust. It listens for DNS queries over UDP and TCP, and forwards them to upstream resolvers over plain or encrypted transports. A plugin-based rule engine lets you filter, rewrite, cache, and shape responses without writing code.

UDP · TCP · DoT · DoH · DoQ · DoH3 Rule chains Persistent cache Web dashboard GPL-3.0

Protocol coverage

Serve UDP and TCP (including io_uring on Linux) and reach upstreams via UDP, TCP, DNS-over-TLS, DNS-over-HTTPS, DNS-over-QUIC, and DNS-over-HTTP/3.

Rule engine

Declarative YAML rules combine matchers (qname, qtype, client IP, ASN, response content…) with actions (forward, cache, redirect, block, rewrite, TTL control…).

Smart caching

Sharded LRU cache with lazy stale-while-refresh, request coalescing, and optional on-disk persistence with periodic dumps.

Resilience

Load-balanced upstream groups, latency-aware selection, fallback with threshold, and best-effort system DNS as a last resort.

Web dashboard

Real-time query log, client statistics, cache viewer, upstream health, slow-query detection, and GeoIP enrichment — with optional SQLite persistence.

Privacy & DNSSEC aware

EDNS Client Subnet support, DNSSEC-safe fallback semantics (SERVFAIL is never silently re-resolved), and encrypted upstream transports.
