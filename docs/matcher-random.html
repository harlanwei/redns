random

Matches each query randomly with a configurable probability. Ideal for A/B testing, probabilistic sampling, or rate limiting a fraction of traffic.

matcher used in: matches

Usage

matches: random 0.5   # matches 50% of queries
matches: random 0.01  # matches 1% of queries

Parameters

Parameter Required Type Default Description
probability Yes number (float) — Matching probability in [0.0, 1.0]. 0.0 never matches, 1.0 always matches, 0.5 matches half of the queries. Values outside the range are rejected at startup.

Details

  • A fresh random draw is made for every query, so the fraction of matched queries converges to the probability over time.
  • Combine with other matchers in one rule for sampled and conditions, or write two rules for “either” semantics.

Examples

# Debug-log 1% of queries for sampling-based troubleshooting
- matches: random 0.01
  exec: debug_print

See also

  • sleep — throttle matched traffic.
