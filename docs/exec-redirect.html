redirect

Rewrites queries for one domain to another, resolving the target downstream and linking the original name with a CNAME — classic alias semantics.

executable recursive used in: exec

Usage

Each line maps one domain to another: from to. Use a YAML block scalar for multiple lines. Blank lines and # comments are ignored; every line must have exactly two fields. 

- tag: alias
  type: redirect
  args: |
    old.example new.example
    # comment lines are ignored
    legacy.internal current.internal

Parameters

Parameter Required Type Default Description
rules Yes string (one from to pair per line) — The redirect map. Queries whose name matches a from entry are answered with the records of to. Matching is exact.

Details

  • The query name is rewritten to the target before the rest of the chain runs (e.g. a forward), then restored.
  • When a response comes back, the question section is fixed up and a CNAME record (TTL 1) links the original name to the target — clients can follow the chain.
  • Queries with no matching rule pass through unchanged.
  • Only the query name is rewritten — qtype and qclass are preserved.

See also

  • use-answer-of — the single-target variant.
  • qname — match names for routing rules.
