resp_ip

Matches any A/AAAA address found in the current response against CIDR ranges. Useful for blocking or rerouting answers that resolve into unwanted networks.

matcher used in: matches

Usage

matches: resp_ip 203.0.113.0/24 198.51.100.0/24

Parameters

Parameter Required Type Default Description
cidrs Yes CIDR / IP (space-separated) — Ranges to match against the answer addresses. A bare IP is treated as a /32 or /128.

Details

  • Only A and AAAA records are inspected; CNAME chains are followed through the answer records.
  • The matcher inspects the current response — combine it with has_resp when the response is produced by an earlier rule.
  • Without a response the matcher returns false.

Examples

# Drop answers that point into a known ad-serving range
- matches: ["has_resp", "resp_ip 203.0.113.0/24"]
  exec: drop_resp

See also

  • client_ip — match the client address instead.
  • ip_set — reusable named IP/CIDR sets.
  • has_resp — check that a response exists.
