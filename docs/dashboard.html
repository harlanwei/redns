Dashboard & API

A Svelte single-page app served by ReDNS itself: real-time query log, client statistics, cache viewer, upstream health, and slow-query detection.

Enabling the dashboard

Build the frontend once (requires pnpm):

$ make dashboard    # builds dashboard/dist from the dashboard/ source tree

Then enable it in the config:

dashboard:
  http: "127.0.0.1:9090"
  static_dir: /usr/share/redns/dashboard/dist  # optional; default: ./dashboard/dist

Open http://127.0.0.1:9090 in your browser.

Features

  • Query log — live view of every query with rcode, latency, upstream, and GeoIP enrichment; arpa queries are hidden from logs and statistics by default.
  • Clients — per-client statistics; hostnames resolved from optional DHCP lease files.
  • Cache viewer — inspect cached entries, hit/miss rates, and evictions.
  • Upstreams — live health, latency, and error state for every upstream.
  • Slow queries — the slowest queries across the retention window.
  • Command palette — keyboard-driven navigation (theme, tabs, search).

Data persistence

By default, dashboard data lives in an in-memory database and is discarded on exit. Set persist: true (and optionally sqlite for the path) to keep query logs and client statistics in a durable SQLite file that survives restarts. The dhcp_leases option accepts dnsmasq (/tmp/dhcp.leases) and hosts-format (/tmp/hosts/odhcpd) files to resolve client IPs to hostnames. GeoIP lookups (via ip-api.com) are cached in SQLite.

HTTP API

The dashboard server exposes JSON endpoints under /api/; the separate api.http listener exposes metrics:

Endpoint Description
GET /api/versionVersion and git commit.
GET /api/upstreamsUpstream health and metrics.
GET /api/cacheCache statistics and entries.
GET /api/logsPaginated query log.
GET /api/logs/slowSlowest queries.
GET /api/clientsPer-client statistics.
GET /api/geoip?ip=…GeoIP lookup (cached; backed by ip-api.com).
POST /api/logs/clearClear the query log.
GET /metrics/upstreamsUpstream metrics (on the api.http listener).
GET /metrics/cacheCache metrics (on the api.http listener).
