Plugins

ReDNS ships with 16 matchers and 21 executables. Each plugin has its own page with a full parameter reference — whether each parameter is required, its type, its default, and what it does. Start with the Rules page if you have not read it yet.

Matchers

Used in matches. They inspect the query or the response produced so far and return true or false.

qnameMatch the query name against domain patterns. qtypeMatch the query type (A, AAAA, MX…). qclassMatch the query class (IN…). client_ipMatch the client source address. resp_ipMatch addresses in the response. cnameMatch CNAME targets in the response. rcodeMatch the response rcode. randomMatch with a given probability. envMatch on an environment variable. ptr_ipMatch the IP in a PTR query name. string_expString expressions over env/metadata. asnMatch the autonomous system of an answer. has_respTrue when a response exists. has_wanted_ansTrue when the response has answers. domain_setReusable named domain set. ip_setReusable named IP/CIDR set.

Executables

Used in exec. They act on the query or the response.

forwardForward to upstream resolvers. cacheLRU response cache, optionally persisted. fallbackPrimary/secondary with a time threshold. ecsAttach EDNS Client Subnet to queries. redirectAlias one domain to another. hostsStatic hosts-file style mapping. black_holeAnswer with fixed IPs (blocking). ttlFix or clamp response TTLs. reverse_lookupAnswer PTR from cached A/AAAA answers. use-answer-ofAnswer with another name's records. metrics_collectorIn-process query/error counters. shuffleRandomize record order (round robin). acceptStop the chain, keep the response. rejectAnswer with an rcode, stop the chain. sleepDelay the query (rate limiting). debug_printLog the full query context. drop_respDiscard the response (client times out). arbitraryServe records added programmatically. udp_serverDeclare a UDP listener as a plugin. tcp_serverDeclare a TCP listener as a plugin.

Containers

sequenceThe rule container that processes every query.
