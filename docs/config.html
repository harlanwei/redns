Configuration

ReDNS is configured with a single YAML file. The top-level schema is small; everything interesting lives in the plugins section. Each key below documents whether it is required, its type, its default, and its meaning.

Top-level keys

Parameter Required Type Default Description
log No map info / stdout Logging settings: level and optional file (see below).
include No list of strings empty list Additional YAML files to load (up to 8 levels of nesting). Plugins from included files are merged into the same namespace.
plugins No list of maps empty list Named plugins: { tag, type, args }. Tags are referenced from rules as $tag.
servers No list of maps empty list Listener definitions (see below). Equivalent udp_server/tcp_server plugin entries are also accepted.
api No map absent (disabled) http: listen address for the JSON metrics API (/metrics/upstreams, /metrics/cache).
dashboard No map absent (disabled) Web dashboard settings (see below and Dashboard & API).
best_effort No boolean false When true and every upstream failed to produce any response, retry once against the WAN-assigned system DNS. DNSSEC-safe: any response an upstream did produce — including SERVFAIL — is returned as-is.
edns_udp_size No integer 1232 EDNS0 UDP payload size advertised to upstreams. 1232 avoids fragmentation; modern networks can handle 4096+.
asn_db No string or list of strings none (auto-downloads default DB) Paths to MaxMind-DB files backing the asn matcher. When omitted and the asn matcher is used, ReDNS auto-downloads the default origin-asn.mmdb database on first use.

log

Parameter Required Type Default Description
level No string info Log level: error, warn, info, debug, trace. The RUST_LOG environment variable takes precedence.
file No string stdout Write logs to this file instead of stdout. The file is truncated on startup.

servers

Each entry defines one DNS listener. You may also declare listeners as udp_server/tcp_server plugins — see their pages for the equivalent options.

Parameter Required Type Default Description
protocol No string udp+tcp Which protocols to serve on the address: udp, tcp, or udp+tcp.
addr Yes string — Listen address, e.g. "0.0.0.0:53" or "[::]:53".
entry Yes string — Tag of the sequence plugin that handles queries arriving on this listener. Required at runtime — ReDNS refuses to start without it.
udp_backend No string epoll epoll or io-uring (Linux + feature). Overrides the CLI default for this listener.
udp_workers No integer auto (2× CPU cores, ≤ 32) Receive-loop worker count for the epoll UDP backend.
udp_max_inflight No integer 2048 Cap on concurrently in-flight UDP handler tasks.

dashboard

Parameter Required Type Default Description
http No string absent (disabled) Listen address for the dashboard web server, e.g. "127.0.0.1:9090". Omit to disable the dashboard.
sqlite No string <config dir>/redns.db SQLite file path for dashboard data. Only used when persist is true; otherwise an in-memory database is used.
persist No boolean false When true, query logs and client statistics are written to a durable SQLite file and survive restarts.
static_dir No string ./dashboard/dist Directory containing the built dashboard frontend. Relative paths resolve against the working directory (-d).
dhcp_leases No list of strings empty list Lease files for resolving client IPs to hostnames: dnsmasq format (/tmp/dhcp.leases) or hosts format (/tmp/hosts/odhcpd).

api

Parameter Required Type Default Description
http No string absent (disabled) Listen address for the JSON metrics API, e.g. "127.0.0.1:8080". Serves /metrics/upstreams and /metrics/cache. Omit to disable.

Complete example

log:
  level: info

servers:
  - protocol: udp+tcp
    addr: "0.0.0.0:53"
    entry: main

plugins:
  # Upstream group 1: Google (DoH + DoT + plain UDP)
  - tag: google
    type: forward
    args:
      upstreams:
        - addr: "https://dns.google/dns-query"
        - addr: "tls://8.8.8.8:853"
        - addr: "8.8.4.4"
      concurrent: 2

  # Upstream group 2: Cloudflare (DoH + DoQ)
  - tag: cloudflare
    type: forward
    args:
      upstreams:
        - addr: "https://cloudflare-dns.com/dns-query"
        - addr: "quic://1.1.1.1:853"

  # Shared cache: 65536 entries, persisted to disk every 5 minutes
  - tag: cache
    type: cache
    args:
      size: 65536
      cache_file: /var/lib/redns/cache.bin
      dump_interval: 300

  # Fallback: primary Google, switch to Cloudflare after 800 ms
  - tag: resolver
    type: fallback
    args:
      primary: google
      secondary: cloudflare
      threshold: 800

  # Main entry sequence
  - tag: main
    type: sequence
    args:
      # Block example.org with a black hole
      - matches: qname example.org
        exec: black_hole 0.0.0.0
      # Serve from cache when possible
      - exec: "$cache"
      - matches: has_resp
        exec: accept
      # Otherwise resolve through the fallback group
      - exec: "$resolver"

api:
  http: "127.0.0.1:8080"

dashboard:
  http: "127.0.0.1:9090"
  persist: true
  sqlite: /var/lib/redns/dashboard.db
