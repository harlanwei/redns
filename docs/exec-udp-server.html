udp_server

Declares a UDP DNS listener as a plugin — an alternative to the servers section for configs that organize everything around plugins.

server plugin named plugin

Usage

- tag: udp53
  type: udp_server
  args:
    entry: main
    listen: "0.0.0.0:53"

Parameters

Parameter Required Type Default Description
entry Yes string (tag) — Tag of the sequence plugin handling queries on this listener. Required at runtime — ReDNS refuses to start without it.
listen No string (IP:port) 127.0.0.1:53 Address to bind, e.g. "0.0.0.0:53".
udp_workers No integer auto (2× CPU cores, ≤ 32) Receive-loop worker count for the epoll UDP backend.
udp_max_inflight No integer 2048 Cap on concurrently in-flight UDP handler tasks.

Details

  • The UDP backend (epoll / io-uring) is selected with the --udp-backend CLI flag, not per plugin.
  • Several listeners can be declared; each can use a different entry sequence.
  • Equivalent to a servers entry with protocol: udp.
