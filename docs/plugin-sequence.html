sequence

The rule container at the heart of ReDNS: an ordered list of rules evaluated for every query. Every listener points at one via its entry.

executable recursive named plugin

Usage

- tag: main
  type: sequence
  args:
    - matches: qname example.org
      exec: black_hole 0.0.0.0
    - matches: ["qtype 1 28", "!has_resp"]
      exec: "$forward"

Parameters

Parameter Required Type Default Description
rules Yes list of maps — The ordered rule list. Each rule: {matches, exec}.
matches No string or list of strings always fires Matcher directives; all must match for the rule to fire. ! negates; $tag references named matchers. See the Rules page.
exec Yes string — The action: type args or $tag reference.

Details

  • Sequences are built last, after all other named plugins, so $tag references always resolve regardless of file order.
  • A listener's entry must name a sequence's tag; anonymous (untagged) sequences cannot be used as entries.
  • A sequence can reference another sequence via $tag — a handy way to reuse a common “preamble”.
