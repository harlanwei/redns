env

Matches when an environment variable is set — or equals a specific value. Evaluated once at startup, so it works as a static feature switch.

matcher used in: matches

Usage

matches: env REDNS_STRICT       # true if the variable is set (any value)
matches: env REDNS_MODE hard   # true if the variable equals "hard"

Parameters

Parameter Required Type Default Description
KEY Yes string — Environment variable name. With only this token, the matcher fires when the variable is set, regardless of its value.
VALUE No string any value (set check) Optional second token. When present, the matcher fires only when the variable's value equals it exactly. Additional tokens are ignored.

Details

  • The check happens when the config is loaded — changing the environment afterwards has no effect.
  • With no arguments the matcher never fires.
  • For per-query dynamic conditions, see string_exp with the $ENV_VAR source.

Examples

# Enable strict blocking only when REDNS_BLOCK_ALL is set
- matches: env REDNS_BLOCK_ALL
  exec: reject 5

See also

  • string_exp — richer string conditions.
  • random — probabilistic conditions.
