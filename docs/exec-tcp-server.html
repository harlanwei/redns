tcp_server

Declares a TCP DNS listener as a plugin — the TCP counterpart of udp_server.

server plugin named plugin

Usage

- tag: tcp53
  type: tcp_server
  args:
    entry: main
    listen: "0.0.0.0:53"

Parameters

Parameter Required Type Default Description
entry Yes string (tag) — Tag of the sequence plugin handling queries on this listener. Required at runtime — ReDNS refuses to start without it.
listen No string (IP:port) 127.0.0.1:53 Address to bind, e.g. "0.0.0.0:53".
udp_workers / udp_max_inflight No integer auto (no effect) Accepted for parity with udp_server; they have no effect on TCP listeners.

Details

  • Several listeners can be declared; each can use a different entry sequence.
  • Equivalent to a servers entry with protocol: tcp.
  • Use protocol: udp+tcp in the servers section to serve both protocols on one address.

See also
