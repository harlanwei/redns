ttl

Fixes every TTL in the response to a single value, or clamps them into a range — a simple lever on cache duration and client-side caching.

executable used in: exec

Usage

- exec: ttl 300       # fix every TTL to 300 seconds
- exec: ttl 300-600   # clamp TTLs into [300, 600]

Parameters

Parameter Required Type Default Description
value Yes string: N or N-M — A single integer fixes all TTLs to that value (seconds). min-max clamps: TTLs below min are raised, above max are lowered, in-between values are kept.

Details

  • Applies to answer, authority, and additional records; the OPT pseudo-record's TTL field (which carries EDNS flags) is left untouched.
  • Place the rule after the action that produced the response (e.g. after forward).

See also

  • shuffle — another response post-processor.
