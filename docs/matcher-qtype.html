qtype

Matches the query type — A, AAAA, MX, and so on — by numeric DNS record type code.

matcher used in: matches

Usage

matches: qtype 1 28   # A and AAAA queries
matches: qtype 15     # MX queries

Parameters

Parameter Required Type Default Description
types Yes integer (space-separated) — DNS record type codes to accept. The matcher fires when the query type is in this set. An empty argument never matches.

Common type codes

Code Type
1A
2NS
5CNAME
6SOA
12PTR
15MX
16TXT
28AAAA
33SRV
257CAA

Examples

# Only resolve A/AAAA for this domain — drop other types
- matches: ["qname example.org", "!qtype 1 28"]
  exec: drop_resp
