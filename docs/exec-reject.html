reject

Answers the query with an error rcode and stops the chain. The polite way to refuse queries you don't want to resolve.

executable flow control used in: exec

Usage

- exec: reject        # REFUSED (5)
- exec: reject 3      # NXDOMAIN
- exec: reject 2      # SERVFAIL

Parameters

Parameter Required Type Default Description
rcode No integer 5 (REFUSED) The response code for the answer. Common values: 0 NOERROR, 1 FORMERR, 2 SERVFAIL, 3 NXDOMAIN, 4 NOTIMP, 5 REFUSED.

Details

  • The response carries no answer records — just the rcode.
  • The chain stops immediately; later rules never run for this query.

See also

  • accept — stop without an error.
  • black_hole — “block” with a successful answer instead.
  • rcode — match on rcodes.
