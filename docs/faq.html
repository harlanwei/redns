Frequently asked questions

Why “permission denied” when binding port 53?

Ports below 1024 are privileged. Run as root, grant the capability (setcap 'cap_net_bind_service=+ep' /usr/local/bin/redns), or use the systemd unit in Operations with AmbientCapabilities=CAP_NET_BIND_SERVICE.

The dashboard page loads but shows no data.

The frontend must be built first: run make dashboard (or cd dashboard && pnpm install && pnpm build) and make sure static_dir points at the built dashboard/dist directory.

Is DNSSEC supported?

ReDNS forwards queries and responses as-is, so a validating upstream protects your clients. The best_effort system-DNS fallback and the fallback plugin deliberately treat SERVFAIL as a terminal answer — re-resolving a DNSSEC-bogus answer through a non-validating resolver would silently defeat DNSSEC.

Where is the cache file stored and what format is it?

Only when you configure cache_file on the cache plugin. It is a ReDNS-specific binary snapshot dumped every dump_interval seconds and on graceful shutdown. If the file is missing or corrupt, ReDNS simply starts with an empty cache.

Does ReDNS support EDNS Client Subnet (ECS)?

Yes. Add the ecs executable to your sequence: with no arguments it forwards the client's address (IPv4 /24, IPv6 /48), or pass a fixed IP to always send a preset subnet.

How do I reset the dashboard logs?

Use the POST /api/logs/clear endpoint, or the clear action in the dashboard UI.

Does the asn matcher require an internet connection?

Only on first use, to download the default database. After that it is served from the local cache. You can avoid the download entirely by providing your own MaxMind DB via asn_db.
