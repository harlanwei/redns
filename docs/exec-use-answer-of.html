use-answer-of

Answers the current query with the records of a single target name, linking the two with a CNAME — the single-target cousin of redirect.

executable recursive used in: exec

Usage

- matches: qname myalias.example
  exec: use-answer-of www.example.com

Parameters

Parameter Required Type Default Description
qname Yes domain name — The target name whose records are used for the answer. A trailing dot is optional. If the target equals the original query name, the plugin does nothing.

Details

  • The query name is rewritten to the target before later rules run — a downstream forward resolves the target — then restored.
  • The response's question section is fixed up and a CNAME record links the original name to the target.
  • The query type and class are preserved.

See also

  • redirect — a whole map of aliases.
  • cname — match CNAME answers.
