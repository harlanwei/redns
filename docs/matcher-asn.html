asn

Matches when any A/AAAA address in the response belongs to one of the given autonomous systems (ASNs) — for example, to block or reroute answers hosted on specific networks.

matcher used in: matches

Usage

matches: asn 13335 15169   # Cloudflare, Google
matches: asn AS13335       # "AS" prefix also accepted

Parameters

Parameter Required Type Default Description
asns Yes integer (space-separated) — Autonomous system numbers, with an optional AS prefix (13335 or AS13335). The matcher fires when any answer address is owned by any listed ASN.

Database requirements

  • Backed by MaxMind-DB files (GeoIP2/GeoLite2 or sapics *-asn databases). Point the top-level asn_db config key at your files.
  • When asn_db is omitted and the asn matcher is used, ReDNS auto-downloads the default origin-asn.mmdb (~10 MB) on first use and caches it under $XDG_CACHE_HOME/redns/ or ~/.cache/redns/.
  • Several files may be listed; lookups use union semantics across all of them.

Examples

# Reroute answers hosted on a specific ASN to a black hole
- matches: ["has_resp", "asn 64500"]
  exec: black_hole 0.0.0.0

See also

  • resp_ip — match by address instead of ASN.
  • Configuration — the asn_db key.
