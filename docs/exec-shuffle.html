shuffle

Randomizes the order of the answer, authority, and additional sections — the classic round-robin technique for spreading clients across the addresses of a multi-A record.

executable used in: exec

Usage

Takes no arguments. Place it after the action that produced the response:

- exec: "$forward"
- exec: shuffle

Parameters

Parameter Required Type Default Description
— No none n/a This executable takes no arguments. All three sections (answer, authority, additional) are shuffled.

Details

  • The shuffle is per-query, so successive clients get different address orders.
  • Records are only reordered — never dropped or duplicated.
