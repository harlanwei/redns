cname

Matches the CNAME targets present in the current response. Handy for catching aliases that point into domains you want to block.

matcher used in: matches

Usage

matches: cname cdn.example
matches: cname .cdn.example   # leading dot = suffix match

Parameters

Parameter Required Type Default Description
patterns Optional string (space-separated) never matches CNAME target patterns, lowercased. A leading dot (.cdn.example) matches any target ending with that suffix; otherwise the match is exact.

Details

  • Only the answer section is inspected; targets are compared without the trailing dot.
  • Without a response, or without CNAME records, the matcher returns false.

Examples

# Block anything that resolves through a tracking alias
- matches: ["has_resp", "cname .tracker.example"]
  exec: drop_resp

See also

  • qname — match the query name.
  • redirect and use-answer-of — create CNAME answers.
